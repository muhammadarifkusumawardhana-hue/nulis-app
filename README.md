# Personal Notes (Flutter)

Aplikasi catatan pribadi berbasis Flutter.

## Fitur utama
- Catatan evergreen
- On‑boarding tutorial
- Kustomisasi tema & sinkronisasi

## Struktur folder penting
- `antigrav/Assets` – aset UI stitch
- `flutter_ver/` – kode Flutter utama
- `v2 redesign/NotesApp/` – versi kedua

## Cara menjalankan
```bash
flutter pub get
flutter run
```
